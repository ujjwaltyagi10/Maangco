# PrepDoc Growth and Conversion Plan

This document is based on the current product flow in the app and focuses on the fastest ways to improve user engagement and increase paid conversions.

## What the product already does well

- Clear niche: interview prep for DSA, system design, and frontend.
- Strong brand consistency across landing, auth, and dashboard.
- Good premium value framing: company-wise questions, roadmap, dashboard, and daily updates.
- A real authenticated experience instead of a static marketing site.
- Subscription state is already tied to backend data, which is the right foundation.

## Biggest friction points

- The landing page explains the product, but it does not aggressively prove why the paid plan is worth buying in the first 10 to 15 seconds.
- The buy decision is mostly deferred until users are already in the app, which is too late for many first-time visitors.
- Social proof exists, but it is not surfaced as a conversion element near the primary CTA.
- Pricing value is stated, but there is not enough side-by-side contrast between free preview and paid access.
- Some of the high-value content is hidden behind the dashboard, so users do not fully feel the premium gap before they are asked to pay.
- The auth flow is functional, but it is still a conversion bottleneck instead of part of the sales journey.

## Improve first impression

1. Add one primary conversion message above the fold.
- Example: "Solve the exact interview problems top companies ask, with a daily roadmap and progress tracking."
- The current hero is good, but the value proposition should be sharper and more outcome-driven.

2. Make the paid outcome concrete.
- Show the result, not just the features.
- Example: "Know what to solve today, what to revise tomorrow, and what to skip entirely."

3. Put the strongest proof next to the first CTA.
- Add a compact trust strip near the main button.
- Include company logos, number of questions, and a short testimonial.

4. Show a real product preview above the fold.
- A dashboard screenshot, roadmap preview, or company filter preview is better than generic marketing copy.
- The user should understand the product before scrolling.

## Improve engagement

1. Add a guided first-time onboarding checklist.
- Example: choose target company, pick goal date, mark current level, start day 1.
- This creates commitment and gives the app a personalized feel.

2. Add streaks or progress momentum.
- Users stay engaged when they can see continuity.
- Even a simple "3-day streak" or "12 problems solved this week" is effective.

3. Make the dashboard more action-oriented.
- Replace passive summary cards with next-step cards.
- Example: "Continue today's roadmap", "Revise 3 bookmarked hard problems", "Resume system design day 12".

4. Surface progress in a way that feels earned.
- Show completion, solved counts, and target readiness.
- Progress should feel like a path to an offer, not just a usage metric.

5. Add more personalized content paths.
- Let users choose "FAANG focus", "Startup focus", or "Frontend focus".
- Personalized paths increase engagement because the content feels relevant immediately.

## Improve conversion to paid plan

1. Move pricing closer to the first decision point.
- Add a pricing section earlier on the landing page.
- Do not make users hunt for the plan.

2. Make annual plan feel like the default smart choice.
- Highlight savings prominently.
- Visually separate "most popular" or "best value" on the yearly plan.

3. Add a feature comparison table.
- Show free vs paid vs premium clearly.
- The user should be able to understand what is locked in 5 seconds.

4. Use premium gates at high-intent moments.
- Best moments: trying to open company filters, advanced sorting, bookmark-heavy workflows, or deep roadmap access.
- Do not block too early; block after the user has seen enough value to care.

5. Use soft paywalls instead of hard walls where possible.
- Let users preview some premium content.
- Lock depth, not discovery.

6. Add stronger urgency and risk reversal.
- Example: "Cancel anytime", "Access updates every day", "No long-term commitment".
- Confidence reduces purchase hesitation.

7. Add proof of outcome, not just testimonials.
- Testimonials are good, but outcome-based proof is stronger.
- Example: "Went from day 1 to system design readiness in 8 weeks."

## Improve the auth flow

1. Treat sign-in as a step toward success, not a dead-end form.
- Add a short benefits recap on the login screen.
- Remind users what they unlock immediately after login.

2. Reduce password friction.
- Google sign-in should be the default recommended path.
- Email/password can remain, but the fastest path should be obvious.

3. Keep the user in context after login.
- Return them to the exact page or premium content they tried to access.
- Avoid sending them to a generic dashboard every time.

4. Show post-login success clearly.
- Immediately confirm what the user now has access to.
- This is a good moment to prompt the subscription upsell if they are not premium.

## Improve the purchase moment

1. Make the premium modal feel like a product summary, not a payment popup.
- Show what the user gets, what they are missing, and why it matters now.

2. Add one clear primary CTA.
- Example: "Unlock full access".
- Avoid competing CTAs in the payment flow.

3. Make the value visible right before checkout.
- Show the exact benefits the user will get after purchase.
- Use a checklist, not a paragraph.

4. Reinforce trust near payment.
- Add "secure payment", "cancel anytime", and "instant activation".

## Engagement loops to add

- Daily streak reminders.
- Resume where you left off.
- Weekly progress summary.
- "Next best question" recommendation.
- Bookmarked question revisit flow.
- Company target mode.
- Goal completion milestones.

## Metrics to track

1. Landing page conversion rate.
- Visitor to sign-in or get-started click.

2. Sign-in completion rate.
- Auth page view to successful login.

3. Premium modal open rate.
- How often users hit a paywall or upgrade moment.

4. Checkout conversion rate.
- Premium modal open to successful payment.

5. Activation rate after purchase.
- Whether users start using premium features after paying.

6. Retention signals.
- Day 1, day 7, and day 30 returning users.

7. Feature adoption.
- Solved questions, bookmarked questions, roadmap completion, and company filter usage.

## Priority order

1. Tighten the landing hero and pricing presentation.
2. Add a stronger comparison between free and paid value.
3. Improve the first-time onboarding experience.
4. Add premium gates at high-intent actions.
5. Strengthen post-login and post-payment guidance.
6. Add retention loops like streaks, reminders, and personalized recommendations.

## Bottom line

The product already has the right foundation. The main opportunity is to make the value of buying feel immediate, obvious, and low-risk before the user reaches the payment step.

The fastest path to better conversions is:

- Sharper above-the-fold value proposition.
- More visible proof and social trust.
- Clearer free vs paid contrast.
- Better onboarding and progress loops.
- Premium prompts at moments of intent, not random interruptions.
